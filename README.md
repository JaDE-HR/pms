# JaDE 프로젝트 현황판

고객사에 **URL 하나로 공유하는 프로젝트 현황판**입니다.
외부 서비스에 의존하지 않습니다. **화면도 데이터도 이 저장소 안에 있습니다.**

```
isens/index.html   화면 (셸 · 고칠 것은 <title> 한 줄)
isens/data.xlsx    PM 이 고치는 원본   ← 커밋되지 않습니다
isens/data.enc     배포되는 암호문     ← 이것만 올라갑니다
```

- **저장소**: `JaDE-HR/pms` — **Public**
- **배포**: GitHub Pages (`main` / root)
- **고객 URL**: `https://jade-hr.github.io/pms/<프로젝트키>/`
- 고객사는 GitHub 계정도 구글 계정도 필요 없습니다. **비밀번호만 알려주면 됩니다.**

---

## 🔴 왜 Public 인데 안전한가

**데이터가 암호문으로만 올라가기 때문입니다.**

| | |
|---|---|
| 저장소에 있는 것 | `data.enc` — AES-256-GCM 암호문 |
| 저장소에 없는 것 | `data.xlsx` — 평문 원본 (`.gitignore`) |
| 비밀번호 | **복호화 키 그 자체**. 해시를 심지 않습니다 |

열람 비밀번호를 맞게 넣어야 복호화가 되고, 복호화가 되어야 화면이 그려집니다.
**틀린 비밀번호로는 데이터가 화면 어디에도, DOM 어디에도 나타나지 않습니다.**
저장소가 Public 이어도, 파일을 받아가도, 비밀번호 없이는 아무것도 읽히지 않습니다.

> 그래서 **무료 플랜으로 유료 플랜보다 나은 보호**가 됩니다.
> (Netlify Pro·GitHub Team 은 저장소만 잠글 뿐, 배포된 데이터 파일은 URL 만 알면 그대로 받아집니다.)

**비밀번호를 잃어버리면 복구할 수 없습니다.** 프로젝트별 비밀번호는 팀 비밀번호 관리처에 기록해 두세요.

## 저장소 구조

```
app/                  ← 표준 앱. 전 프로젝트가 공유합니다. 프로젝트별로 고치지 마세요
  board.js  board.css
  xlsx.mini.js        ← 엑셀 리더 (SheetJS · Apache-2.0)
template/             ← 빈 데이터 템플릿. 새 프로젝트의 data.xlsx 원본
_tools/
  pack.py             ← 엑셀 암호화 (가장 자주 쓰는 도구)
  gen_template.py     ← 템플릿 재생성
  test.js             ← 회귀 테스트 60개 항목
isens/
  index.html  data.enc
<프로젝트키>/…
```

**표준을 고치면 `app/` 한 곳만 바꾸면 되고, 전 프로젝트에 동시에 반영됩니다.**

---

## 갱신 (매주 하는 일)

```
1. isens/data.xlsx 를 엑셀에서 고친다
2. python _tools/pack.py isens        ← 비밀번호를 물어봅니다
3. git add . && git commit -m "W03 주간실적" && git push
```

1분 뒤 고객 화면에 반영됩니다.

> 🔴 **2번을 빠뜨리면 화면이 안 바뀝니다.** 배포되는 것은 `data.enc` 이고,
> `data.xlsx` 는 커밋 자체가 되지 않습니다(`.gitignore`).
> `pack.py` 는 끝나면 왕복 검증(암호화 → 복호화 → 원본 일치)까지 하고 결과를 알려줍니다.

## 새 프로젝트 추가 (5분)

1. `isens/` 폴더를 통째로 복사해 폴더명을 프로젝트키로 바꿉니다
2. `index.html` 의 `<title>` 을 고칩니다
3. `data.xlsx` 를 그 프로젝트 내용으로 채웁니다
   (빈 원본이 필요하면 `template/JaDE_현황판_시트템플릿.xlsx` 를 복사해 쓰세요)
4. `python _tools/pack.py <프로젝트키>` — 이 프로젝트의 비밀번호를 정합니다
5. 커밋 · push

**끝입니다.** 고객사명·로고·기간·진척률·탭 구성은 전부 엑셀에서 읽습니다.

## 로컬에서 미리 보기

브라우저는 `file://` 에서 같은 폴더의 파일도 못 읽고(CORS), 복호화 기능(WebCrypto)도 못 씁니다.
간단 서버를 띄우세요. **`localhost` 는 보안 컨텍스트로 인정되어 복호화가 동작합니다.**

```
cd <저장소>  &&  python -m http.server 8080
→ http://localhost:8080/isens/
```

## 시트별 역할

| 시트 | 화면 |
|---|---|
| **설정** | 제목, 기간, 오픈일, 진척률, 가중치 — **필수** |
| **WBS** | 전체 공정 간트, 진척률 계산 — **필수** |
| 마일스톤 | 월별 진행 맵 아래 칩 줄 |
| 주간업무 | 주간 업무 탭 (오늘 주차가 자동으로 열림) |
| 요건 | 추가개발 탭의 요건 대장 |
| 녹화본 | 녹화본 탭 |
| 산출물 | 산출물 탭 |
| 이슈 | 이슈 탭 |

**시트 이름과 1행 머리글은 바꾸지 마세요.** 열 순서는 바뀌어도 됩니다.

### 🔴 탭은 넣다 뺐다 할 수 있습니다

**엑셀에 그 시트가 없거나 비어 있으면 화면에서도 그 탭이 사라집니다.**
녹화본을 안 쓰는 프로젝트면 `data.xlsx` 에서 녹화본 시트를 지우면 됩니다. 별도 설정은 없습니다.

- 추가개발이 없는 프로젝트면 WBS에 `추가개발` 구분 행을 안 넣으면 됩니다
  → 추가개발 탭이 사라지고, 월별 맵과 진척률 패널도 단일 트랙으로 바뀝니다
- 데이터는 채웠지만 아직 고객에게 안 보이고 싶다면 설정 시트 `숨김탭` 에 `녹화본, 이슈` 처럼 적습니다

### WBS 시트 쓰는 법

주차 칸(1주~24주)을 칠한 구간이 그대로 화면의 막대가 됩니다.
칸을 우측으로 끌면 기간이 늘어나고 지우면 줄어듭니다. 값은 무엇이든 비어 있지만 않으면 됩니다.

- **작업 칸이 빈 행** = 그 모듈의 전체 구간 (검은 막대)
- **진척률 칸** = 비우면 상태값에서 자동 계산, 숫자를 넣으면 그 값이 우선 (작업 행·모듈 행 모두)
- **상태** = 완료 / 진행중 / 예정

### 설정 시트 진척률

`진척률_패키지` 와 `진척률_추가개발` 만 넣으면 `진척률_전체` 는 가중치를 적용해 자동 계산됩니다.
전체 칸은 비워두세요.

### 미리보기기준일

비워두면 오늘 날짜를 씁니다. 특정 날짜 화면을 확인할 때만 채웁니다.
**값이 남아 있으면 화면 상단에 노란 경고 띠가 뜹니다.** 보이면 지우세요.

## 기간이 24주가 아닌 경우

설정 시트의 시작일과 종료일만 바꾸면 주차 수, 월별 카드, 간트 열이 전부 따라갑니다.
템플릿의 주차 칸은 24주 기준이라 기간이 길어지면 WBS 시트 오른쪽에 `25주`, `26주` … 열을 이어서 넣으세요.
(아이센스는 27주라 3열을 더해야 합니다.)

기간을 **줄였을 때** 범위 밖 주차가 남아 있으면 마지막 주로 맞추고
간트 헤더에 `기간을 벗어난 행 N건을 마지막 주로 맞췄습니다` 라고 알려 줍니다.

## 알아두실 점

- 비밀번호는 새로고침할 때마다 매번 물어봅니다 (통과 기록을 남기지 않습니다).
- **데이터를 못 읽으면 예시 데이터를 보여주지 않고 안내 화면을 띄웁니다.**
  (예전 방식은 내장 예시가 그대로 노출돼 고객이 가짜 일정을 보는 사고가 날 수 있었습니다)
- 시트 값에는 `<b>` `<i>` `<u>` `<br>` 만 서식으로 쓸 수 있습니다. 나머지 태그는 글자로 표시됩니다.
- 날짜는 엑셀 날짜 서식이든 `2026-08-03` 같은 글자든 둘 다 알아봅니다.
- 공개해도 되는 현황판이면 `window.BOARD = { plain:true }` 로 암호화 없이 쓸 수 있습니다
  (이때는 `.gitignore` 에서 그 프로젝트의 `data.xlsx` 를 빼주세요).

## 표준을 고칠 때

1. `cd _tools && npm install && node test.js` — **60개 항목이 전부 통과해야 합니다**
2. `app/board.js` 의 `VER` 를 올립니다
3. push하면 GitHub Pages 가 자동으로 다시 배포합니다 (보통 1분 이내)
4. 진행 중인 프로젝트를 흔들고 싶지 않다면, 그 프로젝트의 `?v=` 만 이전 값으로 두고
   `app/board-v1.js` 처럼 이전 버전을 남겨두면 됩니다

화면 하단 우측에 `board v1.0.0` 이 찍혀 있어 어느 버전을 보고 있는지 확인할 수 있습니다.

> `_tools/pack.py` 의 암호문 형식은 `app/board.js` 의 `decrypt()` 와 맺은 계약입니다.
> 한쪽만 고치면 전 프로젝트가 안 열립니다. 테스트 M·N 이 이 교차검증을 담당합니다.
